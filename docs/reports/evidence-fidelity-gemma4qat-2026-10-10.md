# Evidence Fidelity Campaign, first live grid: Gemma 4 31B QAT on Modal (2026-10-10)

Model `gemma-4-31b-it-qat-w4a16-ct` (label `gemma4qat`), self-hosted vLLM on one L40S. 10 paired seeds per family; every arm of a seed runs on the identical task. No resample gate (budget), so single-trial verdicts are noisy (lab log 2026-10-06 E). Ground truth is the project's own simulators and interpreter; no LLM judged anything. Run ids `camp-ef-{belief,tools,comments,tickets,repair}-gemma4qat-001`. Spec: `docs/spec-evidence-fidelity-campaign.md` (§12 build notes).

## Bottom line

1. **Belief (I):** the conflict costs Gemma 4 of 10 (A 10/10 → B 6/10), and every failure names the object's real location. **Restating what the person saw (C) rescues all 4 (10/10); flagging the same sentences in place (D) rescues 1 (7/10).** That is the retrieval-not-attention pattern H-EF2/H-EF3 predict for a carried fact. It is not significant at n = 10 (exact McNemar p = 0.125; Holm 0.75); about 25–30 pairs would decide it.
2. **Tool ids (II):** a small conflict cost (A 10/10 → B 8/10, both failures `unknown_tool`); C 10/10, D 9/10. Same direction as belief, too small to test at n = 10.
3. **Misleading comments (IV, the in-view anchor):** no cost at all. 10/10 in every arm, including E, where the misleading comment is shouted. This fits the earlier null (Gemma 4 reads code correctly) and H-EF1's in-view prediction.
4. **Tickets (III): the arm is invalid, and it exposes an instrument artefact in earlier findings.** Every one of the 50 episodes had exactly 2 turns. Gemma wrote all 11 calls in its first message, *before seeing any tool result*, including a ticket it had not been given yet (`ticket_flag_0_12345`). So even condition A (the true ticket is the trivial `ticket_flag_0`) scored 0/10. Province III's text protocol executes every call in a message; the Province VI fix (stop where a second call begins, one call per turn) was never applied to III. **435 of 531 earlier Gemma 4 Province III records also have ≤ 2 turns,** so F-G4Q-1 ("Gemma 4 fabricates tickets instead of copying them", fresh-seed replicated) and the 6/6 restatement rescue are at retraction risk. Lab log 2026-10-10.
5. **Repair (VI):** the control fails. A (bug in the test's own file) 4/10 is not ≥ 0.8: Gemma is at its repair floor whether or not the cause is local, so the conflict is not the limiting factor here, as spec §5 anticipated. C (data flow) 3/10, D 3/10, X 1/9. Uninterpretable as a rescue test until the floor moves.
6. **Hypotheses at this sample:** control passes for belief, tools and comments and fails for tickets (artefact) and repair (floor). No contrast survives Holm. H-EF1 is descriptively in the predicted direction: carried families drop 0.17 on average, the in-view family 0.00. H-EF4 is unresolved, because both of its families are unusable this run.

## Ops note

The driver's final `modal app stop` and the watchdog both read the app list as "absent" while the app was still deployed with 0 tasks, so no GPU was running. It was stopped manually at 08:20 and verified stopped. `scripts/run_vi_live.py` now reads `modal app list --json`, stops by app id, never treats a failed or empty listing as "stopped", and the watchdog stops on anything but a confirmed "stopped".

## What would make this grid informative

- **Tickets:** apply the Province VI turn boundaries (stop at a second call, one call per turn) to Province III's text protocol as a new protocol version. Then re-measure both F-G4Q-1 and this arm.
- **Belief:** about 25–30 paired seeds, single-shot and cheap (≈ 1 min of GPU per 10 seeds).
- **Repair:** a model above the floor (Nemotron Super on Nebius, native tools), or easier repairs.
