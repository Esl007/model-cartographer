# Demo narration (voice: Microsoft Edge neural TTS, en-US-AndrewNeural)

| Time | Scene | Narration |
|---|---|---|
| 0:03 | map | Benchmarks give a model one score. Model Cartographer finds where a model breaks, and why. Each globe is one model, and each flame is its pass rate in one province of skill, from tracking a story to fixing a bug in a real repository. |
| 0:21 | truth | Every task is generated from a simulated world, so the right answer comes from running that world. There is no LLM judge. Difficulty dials go up until the model stops passing. |
| 0:34 | models | NVIDIA's open Nemotron 3 models are both the subjects and the engine. Nano, Super and Ultra ran forty-five hundred trials through Nebius Token Factory for under six dollars, on identical tasks, so their breaking points compare directly. |
| 0:51 | breaks | Breaking points reports each result in the task's own units. Nemotron 3 Super breaks at twenty-four-call plans with look-alike tool names. Nano breaks at thirteen. Ultra only slips, at twenty-five. |
| 1:06 | ask | Inside the app, Nemotron does the analysis live, through Token Factory. Ask a question. Nemotron 3 Nano, with thinking turned off, routes it in about a second. The app pulls the matching facts from the results store. Nemotron 3 Super answers from those facts only, citing each one, and a deterministic audit checks every number it used. |
| 1:30 | findings | Findings link every weakness to the trials behind it, and each trial to its full transcript. On a failed trial, Nemotron 3 Ultra, the reasoning tier, explains the mistake from the prompt and the verified answer, with the verifier's own classification shown beside it. |
| 1:50 | report | Nemotron 3 Super also writes the capability report, and every figure it quotes is audited against the store. |
| 1:59 | close | Model Cartographer is open source under the MIT license, and it's live at model-cartographer dot vercel dot app. Find out where your model breaks, before your users do. |
